# Firstplace.hub — сайт

Лендинг «Хаб, а не агентство»: 3D-хиро, карта хаба, пакет Base, шоурил работ, форма заявки.

- `index.html` — вся страница (стили, скрипты и иконки внутри).
- `media/`, `media2/` — работы клиентов и видео для шоурила.

Сайт публикуется на firstplace.uz (хостинг с cPanel) и дублируется на GitHub Pages из ветки `main`.

## Заявки в Telegram

Форма отправляет заявку на `send.php`, он пересылает её в Telegram-бот. На хостинге рядом с `send.php` должен лежать `tg-config.php` (скопируйте из `tg-config.example.php` и впишите токен бота и chat id). В git этот файл не хранится. На GitHub Pages PHP не работает, поэтому там форма покажет ошибку отправки.
